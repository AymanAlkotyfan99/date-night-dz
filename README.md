# وزارة الطلعات والشؤون الزوجية 💌

موقع تفاعلي باللهجة السورية، جاهز للنشر على Render. مبني باستخدام HTML وCSS وJavaScript فقط، من دون قاعدة بيانات أو تثبيت مكتبات.

**رقم الواتساب المضبوط:** `+4917662223000` ومحفوظ داخل الإعدادات بالشكل الصحيح `4917662223000`.

## ابدأ من هون

افتح [دليل الرفع والنشر بالعربي](DEPLOY-AR.md). وللقراءة بالمتصفح، افتح ملف `دليل-النشر-بالعربي.html` الموجود مع المشروع.

الدليل بيشرح تجهيز الملفات، إنشاء مستودع GitHub، رفع المجلدات، ربط Render، إعداد النشر، تعديل الموقع لاحقاً، وحل المشاكل الشائعة. فيه كمان طريقة النشر باستخدام `render.yaml` وطريقة رفع اختيارية بأوامر Git.

## إعدادات Render

| الخانة | القيمة |
| --- | --- |
| نوع الخدمة | Static Site |
| Branch | main |
| Root Directory | اتركها فارغة |
| Build Command | `echo "Static site ready"` |
| Publish Directory | `dist` |
| Auto-Deploy | On Commit |

الأمر الموجود في Build Command بيطبع رسالة بس؛ ملفات الموقع جاهزة وما بتحتاج بناء. هالإعدادات بتفترض إن مجلد `dist` وملف `render.yaml` موجودين مباشرة بأول مستوى بالمستودع. طريقة إعداد الموقع الثابت موضّحة في [دليل Render الرسمي](https://render.com/docs/static-sites).

## تخصيص الدعوة

كل التخصيص موجود في `dist/config.js`:

- `husbandName` و`wifeName`: أسماء الزوج والزوجة، وبيجوز تتركهن فارغين.
- `wifePhone`: رقم واتساب دولي، أرقام فقط، بلا إشارة `+` أو فراغات أو `00` بالبداية.
- `opening`: سؤال البداية، نصوص الأزرار، مزح زر «لا»، وتعابير المفتّش.
- `stages`: المراحل الأربع، الخيارات، والجواب المقبول `correctId` بكل مرحلة، أو `correctIds` لقبول عدة أجوبة (مثل السبت والأحد).
- `messages`: الردود المختلفة لكل جواب غلط. خلي ثلاثة ردود على الأقل لكل خيار غلط.
- `comedy`: مؤشر النكد، المفاجآت، وطلب حرية الاختيار.
- `finale`: نص التصريح والرسالة النهائية. القالب بيدعم `{wife}` و`{husband}` و`{day}` و`{place}` و`{food}` و`{time}`.
- `branding`: النص الموجود بتذييل الصفحة وألوان الواجهة.
- `version`: غيّره عند تعديل تجربة الدعوة إذا بدك تلغي التقدم القديم المحفوظ. تعديل خيارات المراحل أو أجوبتها بيلغي التقدم القديم تلقائياً كمان.

الأجوبة الحالية: **السبت، مطعم، شاورما، 2:00 الظهر**. خيارات الأكل: **شاورما، بيتزا، برغر، سوشي**. التذكرة ورسالة الواتساب تعرضان اليوم الذي اختاره المستخدم.

زر الواتساب بيفتح رسالة جاهزة على الرقم المضبوط. المستخدم هو اللي بيضغط إرسال داخل واتساب.

## تشغيل محلي اختياري

لتجربة سريعة افتح `dist/index.html`. ولتجربة أدق، إذا Python مثبت عندك، افتح Terminal ضمن مجلد المشروع وشغّل:

```sh
python -m http.server 4173 --directory dist
```

بعدها افتح `http://localhost:4173`. اضغط `Ctrl+C` لإيقاف السيرفر.

## التقدم والصوت

التقدم محفوظ محلياً بالمتصفح. زر إعادة المغامرة بآخر اللعبة بيصفّر المحاولات وبيحتفظ بتفضيل الصوت. الصوت مطفأ افتراضياً. إذا المتصفح منع التخزين، بتشتغل اللعبة بس ما بينحفظ التقدم بعد الإغلاق.

النسخ التلقائي بيعتمد على صلاحيات المتصفح واتصال HTTPS أو localhost. إذا ما اشتغل، الموقع بيعرض نص الدعوة لتنسخه يدوياً.
