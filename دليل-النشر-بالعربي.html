دليل رفع الموقع على GitHub ونشره على Render 💌

هالدليل خاص بالنسخة الجاهزة date-night-render.zip. رقم الواتساب صار +33605953704. الملفات جاهزة، وباقي ترفعها وتربطها بحسابك.

الفكرة: GitHub بيحفظ ملفات المشروع، وRender بينشر الموقع وبيعطيك رابط تقدر تبعته على واتساب. ما في داعي تفعّل GitHub Pages لتشتغل هالطريقة.

١. فك الضغط وجهّز الملفات

  1. نزّل date-night-render.zip على الكمبيوتر.
  2. اضغط عليه بزر الماوس اليمين واختر Extract All / استخراج الكل.
  3. افتح المجلد الناتج. لازم تلاقي dist وrender.yaml وملفات الشرح بنفس المستوى.
  4. افتح دليل-النشر-بالعربي.html إذا بتحب تقرأ هالدليل بالمتصفح.

ارفع الملفات بعد فك الضغط، مو ملف ZIP نفسه. حافظ على مجلد dist كامل، بما فيه assets. إذا فتحت المجلد ووجدت مجلداً إضافياً جواته بنفس الاسم، ادخل عليه لحتى توصل للمستوى اللي فيه dist.

٢. أنشئ مستودع GitHub

  1. افتح GitHub وسجّل دخولك، أو أنشئ حساب إذا ما عندك.
  2. افتح صفحة إنشاء مستودع جديد.
  3. في Repository name اكتب date-night-trap، أو اسم من اختيارك.
  4. اختر Private إذا بدك كود المشروع يضل خاص بحسابك. Render بيقدر يتصل فيه لما تعطيه صلاحية هالمستودع. خيار Public بيخلي الكود ظاهر للجميع.
  5. اترك خيار إنشاء README التلقائي غير مفعّل لأن النسخة المرفقة فيها README جاهز.
  6. اضغط Create repository.

هالخطوات مبنية على تعليمات إنشاء مستودع من GitHub.

٣. ارفع الملفات من المتصفح

  1. ضمن المستودع الجديد، اضغط uploading an existing file. إذا المستودع فيه ملفات من قبل، استخدم Add file → Upload files.
  2. من المجلد المفكوك على جهازك، حدّد مجلد dist وملف render.yaml وملفات الشرح واسحبهم لمنطقة الرفع. اسحب محتويات المجلد الخارجي، مو المجلد الخارجي نفسه.
  3. انتظر حتى تجهز الملفات. لازم تشوف مسارات مثل dist/index.html وdist/assets/mascot.svg.
  4. اكتب برسالة الحفظ Upload date night website.
  5. اضغط Commit changes.
  6. ارجع لصفحة المستودع وتأكد أن dist وrender.yaml ظاهرين مباشرة، وأن الفرع اسمه main.

إذا الفرع عندك اسمه مختلف، اختاره نفسه لاحقاً في Render، وعدّل branch داخل render.yaml إذا استخدمت طريقة Blueprint. تفاصيل الرفع موجودة في دليل GitHub الرسمي.

٤. انشر على Render — الطريقة اليدوية الأسهل

  1. افتح لوحة Render وسجّل دخولك.
  2. اختر New → Static Site.
  3. اربط حساب GitHub. عند تحديد المستودعات المتاحة للتطبيق، اختَر مستودع date-night-trap.
  4. اختر المستودع من القائمة، ثم تابع إنشاء الموقع.
  5. عبّئ الإعدادات التالية حرفياً:

  2. انتظر حتى ينجح النشر. افتح الرابط اللي بيعطيك ياه Render، وغالباً بينتهي بـ onrender.com.
  3. جرّب اللعبة من جوالك. هاد هو الرابط اللي بتبعته على واتساب، مو رابط مستودع GitHub.

لهالمشروع اختَر Static Site. ما في Start Command ولا قاعدة بيانات ولا npm install. أمر البناء بيطبع رسالة فقط لأن ملفات الموقع جاهزة مسبقاً.

حسب دليل Render للمواقع الثابتة، الخدمة بتدعم النشر التلقائي بعد تحديث المستودع وHTTPS. الاستخدام خاضع لحدود حسابك للباندويث ودقائق البناء.

إعدادات المسارات فوق خاصة بترتيب الملفات المرفق. شرح خانات البناء ومجلد النشر موجود في دليل أول نشر على Render.

٥. طريقة بديلة: ملف render.yaml الجاهز

استخدم هالطريقة بدل الطريقة اليدوية إذا بتحب Render يقرأ الإعدادات من الملف. ما في داعي تعمل الطريقتين لنفس الموقع.

  1. تأكد أن render.yaml موجود بأول مستوى بالمستودع، وبجانبه مجلد dist.
  2. في Render اختر New → Blueprint.
  3. اختر نفس مستودع GitHub والفرع main.
  4. اترك مسار ملف Blueprint هو render.yaml.
  5. أعطِ Blueprint اسماً، وراجع الخدمة المقترحة ثم اضغط زر الإنشاء أو النشر.
  6. بعد نجاح النشر، افتح خدمة الموقع وخذ رابطها.

الملف المرفق بيحدد runtime: static ومجلد النشر ./dist. وجود type: web في YAML صحيح للمواقع الثابتة لما يكون معه runtime: static؛ ما بيحوّل الموقع لسيرفر Node. إذا عندك خدمة سابقة بنفس الاسم، غيّر name لاسم جديد قبل إنشاء Blueprint لتتفادى تعديل خدمة موجودة.

مرجع الإعدادات: Render Blueprint YAML. خطوات ربط الملف بالمستودع: Render Blueprints.

٦. كيف تعدّل الرقم والأسماء والموعد بعد النشر؟

افتح في GitHub ملف dist/config.js، واضغط رمز القلم Edit. الرقم مضبوط بهالشكل:

بدّل الأسماء إذا حابب، وخلي رقم الواتساب أرقام فقط بلا + أو فراغات. الرقم الحالي ما بيحتاج تعديل إضافي.

لتغيير الجواب المقبول، عدّل correctId إلى id موجود ضمن خيارات نفس المرحلة. إذا بدّلت الجواب الصحيح، أضف ثلاثة ردود messages للخيار اللي صار غلط، لأن الإعدادات بتتحقق من وجودها. لتغيير اسم الخيار فقط، عدّل label.

نص رسالة الواتساب موجود في finale.message. خلي الرموز {day} و{place} و{food} و{time} حتى تنحط تفاصيل الموعد تلقائياً.

بعد التعديل اضغط Commit changes على الفرع الموصول مع Render. إذا النشر التلقائي مفعّل، Render بيحدّث الموقع. وإذا كان مطفأ، افتح الخدمة واختر Manual Deploy → Deploy latest commit. تابع نتيجة النشر قبل تجربة التعديل، حسب دليل النشر والتحديثات.

إذا بدك المستخدم يبدأ من الصفر بعد تعديلاتك، غيّر version من 1.0 إلى 1.1 مثلاً. تغيير الرقم وحده ما بيحتاج تصفير التقدم. وفي آخر اللعبة زر لإعادة المغامرة.

٧. فحص سريع قبل إرسال الرابط

  1. افتح رابط Render من الجوال وجرّب زر «لا» أكثر من مرة.
  2. اضغط «إي»، وجرّب جواب غلط وبعده الصح بكل مرحلة.
  3. تأكد أن التذكرة فيها تفاصيل الموعد اللي بدك ياها.
  4. اضغط زر تأكيد الطلعة وتأكد أن واتساب فتح الرقم +33605953704 مع الرسالة الصحيحة. الموقع ما بيرسل الرسالة لحاله.
  5. جرّب نسخ الدعوة وإعادة المغامرة، وتأكد أن العرض مريح على شاشة جوالك.

رقم الواتساب جزء من JavaScript اللي بينزل للمتصفح، لذلك بيكون قابلاً للقراءة من ملفات الموقع حتى لو مستودع GitHub خاص. خصوصية المستودع ما بتخلي الموقع المنشور خاص؛ رابط Render بهالإعدادات متاح للزوار.

٩. رفع اختياري بأوامر Git

طريقة المتصفح بالأعلى كافية. هالقسم إذا عندك Git وبتفضّل Terminal.

استخدم نسخة ZIP المفكوكة بمجلد جديد، وأنشئ مستودع GitHub فارغاً بدون README تلقائي. افتح Terminal داخل المجلد اللي فيه render.yaml وdist، ثم نفّذ الأوامر سطراً بسطر. بدّل YOUR_USERNAME باسم حسابك واسم المستودع إذا غيّرته.

git init
git branch -M main
git add .
git commit -m "Prepare date night website for Render"
git remote add origin https://github.com/YOUR_USERNAME/date-night-trap.git
git push -u origin main

أكمل تسجيل الدخول إذا Git طلب منك. إذا طلب تعريف الاسم والبريد، نفّذ الأمرين التاليين داخل نفس المجلد مع بياناتك، وبعدها أعد أمر git commit ثم أكمل الرفع:

git config user.name "YOUR NAME"
git config user.email "YOUR EMAIL"

استخدم المجلد المفكوك الجديد لهالأوامر، لأن مجلد التطوير الأصلي قد يكون مرتبطاً بمستودع آخر. لا تنفّذ git init من داخل dist؛ نفّذه من المستوى اللي فوقه.

بعد التعديلات المستقبلية:

git add .
git commit -m "Update date invitation"
git push
